# ГКМ «Северное сияние» — карта инфраструктуры и концепция освоения

Статический сайт к решению кейса «Арктический газовый ресурс» (Второй открытый чемпионат ООО «Газпром добыча Ямбург» по решению инженерной задачи).

- Интерактивная карта: существующая инфраструктура Ямала (данные © участники OpenStreetMap, ODbL, выгрузка 24.10.2026) и предлагаемые объекты проекта (трассы схематичны).
- Рынок, технология, сравнение вариантов, экономика, риски, источники.

Подложка: OpenFreeMap. Графики: Chart.js. Карта: MapLibre GL JS.
